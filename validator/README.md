# Wikidéb’IA Validator 0.4.39

Validateur local Python 3 aligné sur la norme 1.2.37 et rétrocompatible avec les révisions antérieures, notamment 1.2.36. La validation ordinaire reste strictement en lecture seule.

La version 0.4.39 ajoute trois barrières éditoriales : détection des résumés à gabarit ou répétitifs (`WDV-EDT-024`), contrôle de l’atomicité des mots-clés (`WDV-EDT-025`) et capitalisation du nom propre `Dieu` (`WDV-EDT-026`). Elle exige également une attestation d’originalité et un extrait réel formulant le mécanisme propre à chaque résumé sous 1.2.37.

La source normative active unique embarquée est `normative_reference/01_normes/WIKIDEBIA_NORME_CONSOLIDEE_1.2.37.md`.
