# Validateur stable Wikidéb’IA 0.4.22

Validateur local Python 3 aligné sur la norme 1.2.20 et rétrocompatible avec les paquets 1.1.0 à 1.2.19. La validation ordinaire reste strictement en lecture seule.

La version 0.4.22 conserve tous les contrôles 0.4.21 et ajoute `WDV-EDT-022`. Sous 1.2.20, le manifeste déclare `editorial_controls.graph_placement_review_path`; le registre doit couvrir chaque occurrence active et attester que les niveaux 1 répondent directement au débat, sont autonomes, structurent une famille distincte et n’ont pas de parent général préférable.

La source active unique embarquée est `normative_reference/01_normes/WIKIDEBIA_NORME_CONSOLIDEE_1.2.20.md`.
