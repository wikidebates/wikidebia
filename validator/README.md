# Wikidéb’IA Validator 0.4.37

Validateur local Python 3 aligné sur la norme 1.2.35 et rétrocompatible avec les révisions antérieures. Le statut explicite `translation_status.en=deferred` autorise la validation française sans titres, pages ni contenus anglais et sans lien interlangue. Les titres anglais verrouillés, les liens existants, les pages anglaises manifestées et les états `ready` ou `published` restent strictement contrôlés.

Norme implémentée : 1.2.35  
Kit recommandé : 2.15.10
