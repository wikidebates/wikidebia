# Migration vers la norme 1.2.0

La migration 1.2.0 modifie le rendu et le workflow sans imposer de migration silencieuse des paquets 1.1.x. Pour une nouvelle production : verrouiller les titres anglais avant les pages françaises, intégrer `{{Lien interlangue}}` dans tous les fichiers français, retirer les balises `<references />`, employer `topic` et `complete-topic` en anglais, documenter la langue réelle et les équivalents des sources, revoir la bibliographie du débat, nettoyer les métadonnées sitographiques et expliciter les référents des titres.

Les paquets historiques peuvent rester sous 1.1.9 et être validés par le validateur compatible. Une migration d’un paquet existant exige une reprise déclarée, la régénération des fichiers et des empreintes, et une revue humaine des sources et titres.
