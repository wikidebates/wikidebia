# Migration 1.2.43

Le validateur 0.4.46 ajoute le contrôle de la sous-partie obligatoire sur les enjeux du débat. La règle peut être activée sur un corpus historique avec `introduction_policy_revision=1.2.43`.

Le contrôle exige le titre dédié, un contenu non symbolique, les attestations d’introduction et au moins deux conséquences concrètes consignées dans la ligne de revue de la sous-partie.
