# Historique documentaire conservé

Ce dossier conserve les versions exactes des documents et rapports remplacés lors du passage de 0.3.0 à 0.3.1, ainsi que les documents autonomes qui figuraient auparavant dans les sources du projet.

La présence de ces instantanés ne crée pas une seconde norme active. La norme active demeure 1.1.9 ; les fichiers historiques servent uniquement à la traçabilité et à la vérification de non-régression.
