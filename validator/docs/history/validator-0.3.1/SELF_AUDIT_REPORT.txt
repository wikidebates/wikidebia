Audit de non-régression 0.3.1 : tous les contrôles 0.3.0 sont conservés. La norme 1.1.9 ajoute WDV-EDT-014 pour la proximité titre–ouverture et WDV-EDT-015 pour l’attestation documentaire des données chiffrées. Les seuils restent déclarés par le paquet, les signaux textuels restent heuristiques et la pertinence des exemples ainsi que le ton ferme sans polémique demeurent soumis à une revue humaine. Le code d’exécution ne contient aucune constante propre à un corpus.
