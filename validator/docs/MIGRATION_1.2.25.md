# Migration de validation vers 1.2.25

Le validateur 0.4.27 accepte les corpus 1.2.25 et applique les mêmes contrôles de contenu que 1.2.24. La nouveauté porte sur le protocole d’exécution du kit, non sur la structure des pages. Les plans de reprise conservent les huit catégories, dont `manual_review`, afin de rester auditables avant leur blocage par le kit.
