# Migration validateur 0.4.22 / norme 1.2.20

Installer le validateur 0.4.22, reprendre explicitement la hiérarchie du graphe, créer le registre de placement des occurrences et déclarer son chemin dans le manifeste. Une occurrence de niveau 1 qui vise principalement un autre argument doit être déplacée sous cette cible. Les corpus antérieurs restent acceptés sans ce registre lorsqu’ils conservent leur norme d’origine.
