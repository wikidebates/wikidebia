# Migration 0.4.72

Implémente le contrat de format 1.2.69. Les sorties courantes sont validées avec `sujet-développé` / `expanded-topic` et `débat-dédié` / `dedicated-debate`. Les corpus antérieurs à 1.2.69 restent lisibles avec `sujet-complet` / `complete-topic` et `débat-détaillé` / `detailed-debate`; une sortie courante ne peut pas mélanger les deux générations de noms.
