# Provenance documentaire consolidée

Les libellés de provenance du catalogue (par exemple « debate prompt », « graph prompt », « Pywikibot audit » ou « validator launch request ») décrivent l’origine historique d’exigences consolidées. Les fichiers originaux désignés par ces libellés ne sont pas distribués séparément dans le paquet actif et aucune reproduction octet pour octet n’est revendiquée.

Leur contenu normatif utile est consolidé dans les fichiers réellement livrés suivants :

- `01_normes/cahier_des_charges_consolide_wikidebia.md` ;
- `01_normes/structures_mediawiki_wikidebia.md` ;
- `01_normes/profils_rendu_wikidebia.md` ;
- `01_normes/workflow_production_wikidebia.md` ;
- `00_sources_reference/DECISIONS_CONVERSATION_CONSOLIDEES.md`.

Chaque étiquette de provenance utilisée dans le catalogue doit être déclarée dans `source_aliases`; chaque alias et chaque chemin normatif doit pointer vers au moins un fichier livré. Les documents historiques effectivement livrés restent dans les dossiers `history/`.
