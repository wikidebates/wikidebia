# Sauvegardes de continuité éditoriale

Ce dossier contient les projections assainies permettant de reprendre une
production longue depuis une autre session. Chaque débat utilise
`continuity/<debate_id>/latest/`; les versions précédentes restent accessibles
dans l'historique Git.

Le contenu attendu et les exclusions de sécurité sont définis dans
`kit/GUIDE_EDITORIAL_ORCHESTRATION.md`, section « Continuité obligatoire sur
GitHub ». Une sauvegarde sans `HANDOFF.md` ni manifeste SHA-256 ne constitue pas
un point de reprise valide.
