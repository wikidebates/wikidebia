# Pages MediaWiki du checkpoint graphe et titres

Le dossier `fr/` contient les 101 pages françaises et leur agrégat, rendus pour
le premier checkpoint. Ces fichiers n’ont pas encore été publiés : le préflight
distant a été bloqué par Cloudflare avant la création du plan et avant toute
écriture MediaWiki.

La copie autoritative complète du checkpoint et ses preuves différentielles sont
conservées dans `../runtime/fr-publication/graph/`.
