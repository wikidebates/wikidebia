# Pages MediaWiki du checkpoint graphe et titres

Le dossier `fr/` contient les 101 pages françaises et leur agrégat, rendus pour
le premier checkpoint. Le checkpoint a été publié et vérifié. Les projections
d’arguments incluent aussi la correction distante qui omet les paramètres
`justifications` et `objections` lorsqu’ils sont vides.

La copie autoritative complète du checkpoint et ses preuves différentielles sont
conservées dans `../runtime/fr-publication/graph/`, avec le plan, le reçu et la
vérification de cette correction ciblée.
