# Migration 2.15.33

Le kit 2.15.33 s’aligne sur la norme 1.2.56 et le validateur 0.4.59. Pour une page anglaise produite comme traduction d’une page française verrouillée, le résumé distant est calculé page par page sous la forme `Translation of the French page [[:fr:X|X]]`, où `X` est le titre canonique français de la même `page_id`. Le résumé est signé avec le plan et revérifié après écriture. Les autres politiques de résumé restent inchangées.
