# Migration 2.15.29

Le workflow de génération doit désormais rechercher, pour chaque argument nouveau, une éventuelle appellation consacrée dans la littérature. La recherche est obligatoire ; l’ajout d’un nom ne l’est pas et doit rester rare.

Le rendu accepte `argument_name` uniquement pour les pages nouvelles dont la revue documentaire conclut `known_name`. Les pages historiques conservent leurs mécanismes de préservation et d’attribution explicite.
