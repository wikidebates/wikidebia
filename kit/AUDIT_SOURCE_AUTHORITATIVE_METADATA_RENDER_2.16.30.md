# Audit — rendu source-authoritative des métadonnées FR→EN (2.16.30)

Régression reproduite : une cible anglaise `page_origin=new` recevait `debate-warnings=Debate generated by AI` ou `argument-warnings=Argument generated by AI` même lorsque les paramètres français correspondants étaient absents. `WDV-MWK-023` bloquait correctement le rendu.

Correctif : le renderer distingue désormais le cycle de vie technique de la cible de la provenance éditoriale française. Les métadonnées mappées sont calculées depuis la présence/valeur françaises effectives ; les valeurs de création françaises ne sont utilisées que si la source française elle-même est `new`. Aucune normalisation silencieuse n’est effectuée et une valeur française inconnue bloque le rendu.

Régressions : absence française → absence anglaise ; valeurs françaises présentes → traduction contrôlée ; source française nouvelle → `Constructed debate` / avertissements IA attendus.
