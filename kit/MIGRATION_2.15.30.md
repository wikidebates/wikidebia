# Migration 2.15.30

Le workflow anglais suit désormais explicitement la norme 1.2.53. La page Debate forme un lot autonome, puis les pages Argument sont traitées par lots de 20 par défaut (25 maximum, 10–15 pour les lots denses) avant une passe inter-lots globale.

La recherche de `name=` est propre à la littérature anglophone. Une référence française n'est jamais traduite comme notice : elle n'est reprise que si une version anglaise réelle est trouvée, avec ses propres métadonnées, et la documentation est complétée par de nouvelles références anglophones.

Le traitement `Citation`→`Quote` conserve son exception stricte : seules `quote` et `date` sont traduites et `Citation traduite par IA` est ajouté à `warnings`.
