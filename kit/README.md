# Wikidéb’IA — Kit 2.2.11

Kit générique de publication et de reprise, aligné sur la norme 1.2.24 et le validateur 0.4.26. Le kit conserve la reprise non interactive, le résumé « Corrections », le bundle unique et toutes les protections distantes.

La syntaxe des modèles `{{Lien Wikipédia}}` et `{{Wikipedia link}}` est contrôlée par le validateur avant toute publication ou reprise ; le kit n’effectue aucune requête Wikipédia.
