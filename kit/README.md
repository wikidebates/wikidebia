# Wikidéb’IA — Kit 2.15.2

Kit générique complet pour extraction, reconstruction, revue éditoriale, traduction, rendu, comparaison distante, exécution contrôlée et clôture des Works. Il est aligné sur la norme 1.2.29 et le validateur 0.4.31.

La révision 2.15.2 restaure `{{Quote}}` comme nom du modèle anglais correspondant à `{{Citation}}`. Elle conserve les paramètres documentaires verrouillés et toutes les fonctions du bundle source 2.4.0, contrôlées par un inventaire de non-régression permanent.
