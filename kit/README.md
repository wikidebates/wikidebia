# Wikidéb’IA — Kit 2.15.1

Kit générique complet pour extraction, reconstruction, revue éditoriale, traduction, rendu, comparaison distante, exécution contrôlée et clôture des Works. Il est aligné sur la norme corrective 1.2.28 et le validateur 0.4.30.

La révision 2.15.1 corrige la cohérence des sources actives, complète le diagnostic `doctor` et restaure les modes exécutables historiques de `graph-extract` et `corpus-init-from-snapshot`. Aucun comportement distant de 2.15.0 n’est affaibli.

Voir les guides spécialisés pour chaque phase.
