# Migration vers le kit 2.10.0

Le kit 2.10.0 ajoute le rendu final local avec `corpus-workspace-render`. Il accepte une `translated-copy/` créée sous la norme 1.2.26, exige l’empreinte de traduction, migre le résultat vers 1.2.27 et crée `rendered-copy/`. Toutes les pages françaises reçoivent leur lien interlangue anglais ; les citations sont rendues selon le verrou 2.9.1.
