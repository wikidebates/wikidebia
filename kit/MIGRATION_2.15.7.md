# Migration vers le kit 2.15.7

Le kit 2.15.7 s’aligne sur la norme 1.2.32 et le validateur 0.4.34.

- la revue du vocabulaire bloque les majuscules décoratives dans les noms communs ;
- les noms propres et acronymes conservent leur graphie canonique avec justification ;
- les doublons ne différant que par la casse sont bloqués ;
- la traduction anglaise applique la même politique.

Les workspaces antérieurs doivent être régénérés ou migrés afin d’ajouter les champs de capitalisation.
