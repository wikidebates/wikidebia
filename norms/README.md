# Wikidéb’IA — Normes 1.2.34

La révision 1.2.34 autorise une publication française autonome lorsque `translation_status.en=deferred`. Aucun titre anglais, aucune page anglaise et aucun lien interlangue ne sont alors requis. Les portées anglaises restent bloquées jusqu’au passage à `ready` ou `published`.
