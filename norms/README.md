# Wikidéb’IA — Normes 1.2.43

La révision 1.2.43 rétablit une sous-partie obligatoire `Enjeux du débat` dans toute introduction française, avec l’équivalent `Stakes of the debate` en anglais. Cette rubrique doit exposer des conséquences concrètes propres au sujet, sans recopier le graphe argumentatif ni se réduire à une liste abstraite de domaines.
