# Wikidéb’IA — Normes 1.2.48

La révision 1.2.48 conserve exactement les paramètres historiques `débat-détaillé` / `detailed-debate`. L’arrêt du parcours à une frontière ne supprime plus le paramètre de la page. Les relations locales peuvent être omises uniquement après attestation et information du propriétaire.

La révision 1.2.46 sur l’inventaire exhaustif des notions spécialisées reste intégralement active.
