# Wikidéb’IA — Normes 1.2.79

La révision 1.2.79 impose des résumés MediaWiki individualisés pour toutes les mutations issues d’une reprise de corpus validé : le plan signe la politique et le résumé de chaque page, l’exécuteur les recalcule avant écriture et les vérifie après écriture. Elle conserve intégralement la politique différentielle des métadonnées préexistantes de 1.2.78.
