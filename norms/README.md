# Wikidéb’IA — Normes 1.2.46

La révision 1.2.46 impose un inventaire exhaustif, sous-partie par sous-partie, de toutes les notions spécialisées à expliquer ou à lier. Elle remplace le contrôle trop étroit des seuls groupes de notions voisines.

La révision 1.2.45 impose une cohérence locale des liens Wikipédia explicatifs : les notions spécialisées de même rang sont examinées ensemble et toute asymétrie doit être justifiée.

La révision 1.2.44 interdit le point final dans une simple notice documentaire placée à l’intérieur d’une balise `<ref>`. Le point n’est conservé que si la note constitue elle-même une phrase explicative complète et que cette exception est attestée.
