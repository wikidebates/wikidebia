# Migration vers la norme 1.2.37

La migration est nécessaire pour les nouvelles productions qui veulent bénéficier des barrières éditoriales renforcées. Les corpus historiques conservent leur révision déclarée.

Pour chaque mot-clé, attester `atomic_concept=true`. Une expression de plus de deux mots ou comportant un connecteur n’est admise que comme locution lexicalisée avec `multiword_exception=true` et une justification spécifique. Les mini-rubriques productives sont remplacées par un concept simple.

Pour chaque résumé, supprimer les charpentes génériques, développer le mécanisme propre au nœud et compléter la revue avec `originality_reviewed=true` et un `mechanism_statement` réellement présent dans le texte. Vérifier également la majuscule de `Dieu` lorsqu’il s’agit du nom propre.
