# Audit normatif — 1.2.3

La révision 1.2.3 applique la décision du propriétaire de tester directement la page Débat plutôt qu’une sous-page utilisateur. La page Débat française canonique est la première écriture distante, doit être absente dans le plan et est créée avec `createonly`. Son reçu signé est revérifié avant toute autre page.

La norme, le workflow, le catalogue d’exigences, la matrice de traçabilité, le validateur recommandé et le kit sont alignés. Les règles 1.2.0–1.2.2 restent actives sauf la procédure de test utilisateur, explicitement remplacée.
