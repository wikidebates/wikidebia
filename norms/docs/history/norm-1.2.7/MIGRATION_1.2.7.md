# Migration vers la norme 1.2.7

La révision 1.2.7 ne change pas le contenu éditorial exigé des corpus 1.2.6. Elle remplace uniquement les sources génériques afin de réparer la provenance et l’auto-audit.

Pour un corpus déjà conforme à 1.2.6 : mettre à jour les versions déclarées, utiliser le validateur 0.4.7 et le kit 2.1.7, puis régénérer les empreintes et exécuter toutes les portées.
