# Migration 1.2.52

Cette révision ajoute une revue documentaire obligatoire des appellations consacrées pour les pages Argument nouvelles. Elle ne modifie pas les noms historiques et ne crée aucun quota de pages nommées.

Le résultat normal d’une recherche est `none`. `nom` / `name` n’est émis que lorsque la revue fournit une appellation réellement attestée pour le même raisonnement.
