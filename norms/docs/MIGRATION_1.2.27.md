# Migration vers la norme 1.2.27

La révision 1.2.27 active le rendu bilingue déterministe. Elle exige un lien interlangue direct sur chaque page française et autorise les citations verrouillées dans les pages Argument. La projection anglaise traduit uniquement `citation` et `date`, conserve tous les paramètres documentaires et ajoute `Quote translated by AI` à `avertissements-citation` avec le séparateur `, `.
