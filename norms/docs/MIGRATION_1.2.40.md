# Migration vers la norme 1.2.40

La révision 1.2.40 autorise la conservation d’un résumé historiquement absent uniquement lorsqu’un inventaire source attesté le prouve. Le verrou utilise `summary_provenance=historical_absent` et le manifeste active `historical_summary_absence_revision=1.2.40`. Les pages nouvelles conservent un résumé obligatoire.
