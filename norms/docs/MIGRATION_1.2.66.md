# Migration 1.2.66

La révision 1.2.66 ajoute la filiation directe `titre-affiché`→`displayed-title`, la détection du prédicat principal, la revue différentielle du métadiscours et de nouvelles familles de risques sémantiques. Le registre de traduction courant conserve des empreintes et preuves de champ. Une traduction nouvelle doit obtenir deux passes de convergence indépendantes propres avant application. Les anciens artefacts restent lisibles selon leurs versions de schéma; `concept_id` demeure optionnel pour eux.
