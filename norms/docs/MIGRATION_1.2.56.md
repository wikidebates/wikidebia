# Migration 1.2.56

Cette révision ne réécrit aucun contenu traduit automatiquement. Elle change le **mode de contrôle** de la traduction : les règles de forme deviennent différentielles par rapport à la source française validée. Une forme source historique déjà acceptée reste traduisible telle quelle ; seule une dégradation introduite dans la cible est bloquée.

Nouveaux points de revue : inventaire sémantique des titres, provenance réelle des recherches, distinction `name=`/keywords, cohérence URL/DOI, signal de complétude des Quote et validation sur extraction fraîche de l’archive finale.

Alignement recommandé : validateur 0.4.59, kit 2.15.33.
