# Maintenance 1.2.87 / 0.4.100 / 2.16.32

Cette maintenance ne modifie aucune règle normative. Elle aligne le validateur sur la provenance historique déjà prescrite par la norme : les verrous FR/EN autoritatifs déterminent si un résumé est historique, autorisé ou historiquement absent, indépendamment de l’état transitoire de l’orchestrateur. Les contrôles de création restent inchangés pour les résumés réellement nouveaux.
