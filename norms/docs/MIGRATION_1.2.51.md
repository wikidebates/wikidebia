# Migration 1.2.51 — noms d’arguments explicitement attribués

La révision 1.2.51 ne transforme pas une absence historique de `nom` / `name` en donnée historique. Elle ajoute un registre séparé, explicitement approuvé par le propriétaire, qui autorise l’ajout exact du paramètre sur les seules pages listées. Les autres paramètres protégés restent inchangés.
