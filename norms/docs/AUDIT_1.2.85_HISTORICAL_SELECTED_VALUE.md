# Audit 1.2.85 — valeur éditoriale sélectionnée des textes historiques

Statut : **PASSED**.

La norme 1.2.85 corrige le cas où une introduction historique restait utilisée comme valeur effective après une autorisation propriétaire. Désormais l’historique est la provenance ; la valeur finale autorisée devient la valeur éditoriale sélectionnée. Les contrôles de structure, de sous-parties, de verrou, de changeset, de rendu, de checkpoint 2 et de traduction portent sur cette valeur sélectionnée.

La validation reste différentielle : une nouvelle sous-partie explicitement autorisée reçoit les contrôles pertinents, sans imposer rétroactivement les règles de création aux sous-parties historiques inchangées. Une portée structurée empêche toute modification parasite hors consentement.
