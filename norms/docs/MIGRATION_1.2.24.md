# Migration vers la norme 1.2.24

La migration ajoute une convention de rédaction facultative mais contrôlée pour les introductions et les résumés. Les corpus migrés attestent que les notions techniques ont été soit expliquées dans la prose, soit liées avec le modèle Wikipédia localisé lorsque son premier paragraphe suffit. Toute occurrence du modèle respecte la langue de la page, la syntaxe exacte, la première occurrence utile et l’absence de valeur documentaire.

Le contenu argumentatif, les titres, le graphe et les références ne sont pas modifiés par cette seule migration.
