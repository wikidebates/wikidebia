# Migration vers la norme 1.2.8

La révision 1.2.8 ne change pas le contenu éditorial exigé des corpus 1.2.6 ou 1.2.7. Elle remplace les composants génériques pour corriger la traçabilité, les exemples actifs et une condition du schéma de manifeste.

Pour un corpus déjà conforme : mettre à jour les versions déclarées, utiliser le validateur 0.4.8 et le kit 2.1.8, régénérer les empreintes et exécuter toutes les portées.
