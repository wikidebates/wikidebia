# Correctif normatif appliqué le 23 juillet 2026

Décisions actives ajoutées après la livraison 1.0.6 :

1. La valeur française obligatoire est `avancement=Débat construit`.
2. Une paire de pages Débat/ Debate peut avoir un seuil d'âge ou un cadrage juridictionnel différent lorsque les propositions publiques nationales diffèrent. Le bilinguisme impose l'équivalence du graphe d'arguments, pas l'identité littérale du cadrage politique.
3. Les opérations de comparaison distante sont strictement en lecture seule. Aucun script du validateur ne publie une modification.
4. La configuration Pywikibot historique est conservée séparément du paquet documentaire, afin de préserver la connexion sans intégrer de secrets dans les archives publiques du validateur.
