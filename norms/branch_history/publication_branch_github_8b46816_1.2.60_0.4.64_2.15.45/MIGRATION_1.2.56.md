# Migration 1.2.56

La révision 1.2.56 remplace, pour une création anglaise qui est la traduction d’une page française verrouillée, le résumé générique `Content generated by ChatGPT 5.6` par `Translation of the French page [[:fr:X|X]]`. `X` est le titre canonique français de la même `page_id`. Le plan et la relecture distante vérifient le résumé exact. Les autres politiques de résumé et les liens interlangues de contenu restent inchangés.
