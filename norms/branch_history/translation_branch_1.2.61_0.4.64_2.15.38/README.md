# Wikidéb’IA Normes 1.2.61

Révision normative active et cumulative du projet Wikidéb’IA.

La révision 1.2.61 ajoute les tests de régression sémantique issus des audits, la portée structurée des `name=`, l’attestation sujet/prédicat/portée/modalité et un plan de revue adaptatif calculé avant traduction.
